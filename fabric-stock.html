Fabric stock status

How it works. Pick your supplier code above to see all your fabrics. For each fabric tap Yes or No for availability and, if you can, type the metres in stock. Then press Save. You can also upload an Excel or CSV file instead.
Upload a file instead (Excel or CSV)

The file needs a column with the fabric code, and an available column (Yes / No) and/or a quantity column (metres). An optional note column is kept too. If only quantity is given, more than 0 counts as available and 0 as not available. Easiest: download your list as a template, fill it in and upload it back.
